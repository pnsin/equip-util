# 장비 가동률 관리 시스템

팀원이 장비 사용실적을 입력하면 주·월·분기·반기·연 단위 가동률을 바로 보여 주고,
i-Tube 장비일지 업로드 양식을 그대로 내려받을 수 있는 Streamlit 앱입니다.

## 화면 구성

| 메뉴 | 하는 일 |
|---|---|
| 📊 대시보드 | 기간 단위 선택 → 가동률·사용시간·사용료·지원기관 수, 전기 대비 증감, 목표 대비 달성률, 기간별 추이, 장비별 가동률, 사용목적·활용유형·기관별 구성 |
| 🗓️ 달력 입력 | 월 달력에서 날짜를 눌러 그날 쓴 장비를 표로 입력·수정·삭제. 장비·업체는 목록에서만 고르고, 사업자번호·업종은 업체 목록에서 자동으로 채움. 하루치 입력을 다음 날·다음 평일·지정 기간(주말·공휴일 제외 가능)으로 복사 |
| ✍️ 기간 실적 입력 | 업체 목록에서 기관을 고르면 사업자번호·업종·세부지원내용을 지난 실적에서 자동으로 채움. 장비를 여러 개 고르고 장비별 시간만 입력하면 한 번에 저장. i-Tube 규칙(같은 해, 2개월 이내, 정수 시간, 사업자번호 10자리 등)을 저장 전에 검사 |
| 📋 실적 조회·수정 | 기간·장비·기관·담당자로 찾고 표에서 바로 수정·삭제 |
| 📥 엑셀 내려받기 | ① i-Tube 제출용 장비일지 (원본 양식의 헤더·드롭다운·업종→품목→세부품목 연동까지 재현) ② 가동률 분석 보고서 (요약/장비별/월별/목적별/유형별/실적목록) |
| 🏢 업체 정보 입력 | 기업명·사업자등록번호·담당자·연락처·업종/품목/세부품목 등록. 실적 입력 화면은 여기 등록된 업체만 고를 수 있음 (같은 회사가 다른 이름으로 집계되지 않도록) |
| 👤 담당자 정보 입력 | 팀원 이름·연락처·이메일·담당업무·재직 여부. 실적 입력 화면에서 담당자를 이 목록에서 고름 (퇴직자는 재직을 끄면 새 입력 목록에서만 빠짐) |
| 🔧 장비 정보 입력 | 장비 추가·수정, 장비별 연간기준시간, 도입일·불용일, 가동률 산정 대상 여부 |
| ⚙️ 설정 | 연간 기준시간(기본 2,000h), 목표 가동률, 기존 엑셀 실적 가져오기, i-Tube 공식 빈 양식 등록, 백업·복원 |

## 가동률 계산 방식

- **가동률 = 사용시간 합 ÷ 가용시간 합 × 100** (가동률 산정 대상 장비만)
- **가용시간 = 연간 기준시간 × (기간 일수 ÷ 그해 일수)**
  - 기본 2,000h/년이며, 설정에서 바꾸거나 장비마다 따로 지정할 수 있습니다.
  - 도입일 이전·불용일 이후는 빠집니다.
  - 진행 중인 기간은 기본적으로 오늘까지의 가용시간으로 나눕니다 (대시보드에서 끌 수 있음).
- **사용시간 배분**: 실적 한 건(예: 7/25~8/10, 20h)을 사용기간에 하루 단위로 고르게 나눠 담습니다.
  휴무일자포함이 N이면 주말·공휴일을 빼고 나눕니다. 그래서 주·월 경계를 걸친 실적도 정확히 잘립니다.
  설정에서 '사용시작일에 전부 반영'으로 바꿀 수 있습니다.

## 배포 (Streamlit Community Cloud)

1. 이 폴더 전체를 GitHub 저장소에 올립니다. 실적 데이터와 장비 목록은 코드에 들어 있지 않으므로 Public 저장소여도 됩니다.
2. https://share.streamlit.io → **Create app** → 저장소 선택, Main file path: `app.py` → Deploy.
3. 앱의 **Settings → Secrets**에 `.streamlit/secrets.toml.example`을 참고해 입력합니다.
   - `app_password`: 팀 공용 접속 비밀번호
   - `[gsheets]`, `[gcp_service_account]`: 데이터를 저장할 구글 시트 (아래 참고)

### 데이터 저장: 구글 시트 (중요)

Streamlit Cloud는 앱이 재시작·재배포될 때 서버의 파일이 초기화됩니다. 구글 시트를 연결하지 않으면
데이터가 임시 파일에 저장되어 **사라질 수 있습니다.**

1. 구글 드라이브에서 빈 스프레드시트를 하나 만듭니다 (예: `장비가동률 데이터`).
2. **공유** → 서비스 계정 이메일(`…@….iam.gserviceaccount.com`)을 **편집자**로 추가합니다.
   전극 공정 관리 시스템에서 쓰는 서비스 계정을 그대로 써도 됩니다.
3. 시트 주소의 `/d/`와 `/edit` 사이 문자열을 Secrets의 `[gsheets] spreadsheet_id`에,
   서비스 계정 키 내용을 `[gcp_service_account]`에 넣습니다.

앱이 처음 연결되면 `장비` / `업체` / `담당자` / `사용실적` / `설정` 탭과 열 제목을 자동으로 만듭니다.
시트에서 데이터를 볼 수는 있지만 **1행 열 제목은 바꾸거나 옮기지 마세요.** 수정은 앱에서 하는 것을 권장합니다.
장비 목록은 코드에 넣지 않았으니, 처음에 기존 장비일지 파일을 가져오면 Sheet4의 장비 목록이 함께 등록됩니다.

## 처음 쓸 때

1. **담당자 정보 입력**에서 팀원을, **업체 정보 입력**에서 의뢰 업체를 등록합니다.
2. **설정 → 기존 엑셀 실적 가져오기**에 지금까지 작성한 i-Tube 장비일지 파일을 올리면 실적이 한 번에 등록됩니다 (중복은 건너뜀).
3. **장비 정보 입력**에서 장비별 도입일과 가동률 산정 대상 여부(부대시설 제외 등)를 확인합니다.
4. 이후에는 팀원 각자 **실적 입력**에서 입력하고, 분기마다 **엑셀 내려받기**에서 파일을 받아 제출합니다.

## 로컬에서 실행 (Python이 있는 PC)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 테스트

계산·i-Tube 규칙·저장 로직은 `tests/`의 자동 테스트로 확인합니다 (구글 시트 없이 실행).

```bash
pip install -r requirements.txt pytest
pytest -q tests
```

GitHub에 올리면 Actions가 같은 테스트를 자동으로 돌립니다.
